::: callout key
**핵심 결론**
1. **메인 = 서사 + 해금 레일, 성장 = 오픈월드** — 메인 XP는 약 260으로 고정이고, 레벨은 챌린지·사이드로 오른다. 메인은 레벨 게이트로 성장을 '요구'하는 쪽이다
2. **'수업 = 튜토리얼' 포장** — 주문 습득이 세계관 속 사건이라 튜토리얼 피로가 적다. 메인이 탐험 시스템을 한 번씩 가르치고 나머지는 월드에 남긴다
3. **'파수꾼의 시험' 템플릿을 네 번 변주한다** — 합류 → 조사 → 혼자 입장 → 퍼즐·전투 교대 → 수호자 → 펜시브 기억 → 지도 내실 보고. 제작 효율과 '보상 = 이야기'를 함께 얻는다
4. **정체는 모두 '보이지 않는 조건'에서 생긴다** — 조사 목표의 완료 조건, 편지 트리거, 레벨 게이트. 목표 문구가 명확한 만큼 숨은 조건의 마찰이 더 크게 느껴진다
5. **이야기는 두 축이 네 번의 시험으로 엮인다** — 외적 축(란록·룩우드)은 시간 압박을, 미스터리 축(이사도라)은 '다음 시험을 할 이유'를 만든다. 두 축은 저장소 앞의 마지막 질문에서 만난다

## 2. 시스템 — 퀘스트가 생성·진행·완료되는 규칙

::: callout key
**요약**
등록은 자동, 시작은 대화, 끝은 보고. 실패 상태가 없고 '일시 중단'도 명시적 상태가 아니라 추적 전환일 뿐이다. 메인은 학생 판타지와 선택받은 자 판타지를 번갈아 주면서, 전투·탐험·성장·수집·관계·월드 시스템을 정해진 순서로 연다.
:::

::: details 진행 규칙과 예외 처리
- **순차와 병렬** — 퀘스트 내부는 엄격한 순차(활성 목표 1개). 병렬성은 퀘스트 단위 — 챕터마다 메인 2–5개 + 과제 + 사이드가 동시 활성. 리드 디자이너가 밝힌 '여러 목표를 겹쳐 제시하는' 오픈월드 철학과 일치
- **체크포인트와 저장** — 퀵세이브 없음. 수동 저장(다중 슬롯) + 자동 저장. 시험 던전은 마지막 퍼즐 이후 보스 처치까지 수동 저장 불가 구간이 있고, 입장 후 입구로 되돌아갈 수 없다는 제보
- **실패와 재시작** — 실패 판정 없음. 사망은 마지막 체크포인트 재시작, 잠입 발각은 대부분 전투로 전환
- **난이도** — 스토리·쉬움·보통·어려움 4단계, 언제든 변경 가능. 난이도와 별개로 레벨 게이트가 '적정 전투력'을 보장하는 이중 구조
- **숨은 조사 대상** — 특정 오브젝트 조사가 완료 조건인데 목표 문구에 드러나지 않으면 버그로 오인된다 (퍼시벌 시험의 텐트 속 편지). 다음 메인이 안 뜨면 부엉이 우편 미열람·과제 미완료가 주원인
- **데이터 구조 추정** — Quest ID · State · Objective ID · Trigger · Completion Condition · Reward · Next Quest에, 관찰로 추정한 Chapter ID · Prerequisite(레벨·주문·편지·시간대) · Quest Beacon · Hint VO · Save Lock · World State Flag를 더했다. 미션 디자이너 포트폴리오에 따르면 '서사 비트 · 퀘스트 로그 목표 · 체크포인트 플로차트'를 먼저 만들고 UE4에서 비컨·대화·힌트 VO를 구성하는 순서였다
:::

### 잘 작동한 점 {강점}
- '수업 = 튜토리얼' 포장 — 주문 습득이 세계관 속 사건이라 튜토리얼 피로가 적음

- 기숙사 전용 퀘스트 4종이 같은 목적지(잭도우의 영면)로 수렴 — 적은 비용으로 기숙사 정체성 표현
- 부엉이 우편으로 '누가 나를 부르는가'를 명확히 해 NPC 주도의 흐름을 만듦
### 불편하거나 모호한 점 {약점}
- 레벨 게이트 충돌 — 메인 XP가 적어 챕터 전환부에서 사이드·수집을 사실상 강제. 에필로그 Lv34 불만이 특히 많음
- 숨은 트리거 — 편지 열람·과제 완료 조건 구간에서 '다음 메인이 안 뜬다'는 문의 반복
- 선택의 미회수 — 비밀 공유·어둠의 마법 습득 등이 이후 구조에 거의 영향 없음
- 조사 목표의 완료 조건이 목표 문구에 드러나지 않음
:::

GDC 2024 리드 디자이너 발표에 따르면 기획 단계 557개 미션이 출시 때 약 130개로 줄었다. 이 축소 과정에서 선택 결과 회수 같은 '연결 콘텐츠'가 우선순위에서 밀렸을 가능성이 있다 (추론).

## 3. UI·UX — 요청형 안내와 보이지 않는 조건

::: callout key
**요약**
로그는 '주인공의 일기'다. 퀘스트 설명이 1인칭 일지체로 쓰이고 목표를 달성할 때마다 문단이 쌓여, 진행 상황이 곧 이야기로 남는다. 안내는 '요청형'이다 — 목표 문구와 금빛 궤적을 필요할 때만 부르고 HUD 요소를 하나씩 끌 수 있어, 탐험의 자율성과 안내가 균형을 이룬다.
:::

|---|---|---|
| 발견 | 퀘스트 해금 알림, 편지 수신 알림, 로그의 챕터 헤더와 '???' 슬롯, 맵의 노란 마커 | 자동 해금 구간은 명확. 편지·과제 트리거 구간과 레벨 게이트에서 '다음 메인이 안 뜬다'는 혼란 |

| 추적·이동 | 목표 문구, 맵·미니맵 마커, 매혹된 나침반(금빛 궤적) | 목표 문구가 짧아 인지 부담이 적음. 야외는 쾌적하지만 성 내부는 층·계단 구조 때문에 궤적 의존도가 높음 |

::: details UX 평가와 개선안
- **명확성** — 메인 목표 문구는 짧고 명확하다. 반면 조사 목표의 완료 조건, 편지 트리거, 레벨 게이트는 불명확 — 정체 지점이 모두 '보이지 않는 조건'에서 발생
- **일관성** — 색상 체계(메인 노랑·사이드 은색·과제 흰색)와 시험 구조는 일관되다. 반면 다음 메인이 열리는 방식(자동·편지·과제·레벨)은 섞여 있다
- **자율성과 안내의 균형** — 궤적을 필요할 때만 부르는 '요청형 안내' + HUD 개별 토글로 좋은 균형. 다만 성 내부는 궤적 없이 길찾기가 어렵다
- **접근성** — 난이도 4단계(언제든 변경), 스토리 난이도의 퍼즐 시간 제한 제거, HUD 개별 토글, 거미공포증 모드

| 문제 | 개선안 | 부작용·리스크 |
|---|---|---|
| 편지 트리거를 놓쳐 다음 메인이 안 뜸 | 트리거 편지는 수신 즉시 '읽기' 원버튼 팝업, 로그 '???' 슬롯에 '편지 확인 필요' 표시 | 알림 피로 → 트리거 편지에만 한정 |
| 레벨 게이트에서 목적 상실 | '???' 슬롯에 요구 레벨 + 근처 추천 활동 안내 | 안내가 체크리스트처럼 느껴져 탐험의 자발성 저하 |
| 조사 목표에서 정체 | 조사 대상 근처에서 하위 목표 표시, 일정 시간 정체 시 동행 NPC 힌트 VO | 발견의 재미 감소 |
| 시험 던전 복귀 불가를 모르고 입장 | 입장 홀드 시 '되돌아갈 수 없음 · 준비 확인' 확인창 | 몰입 연출이 한 번 끊김 |
| 한글판 핵심 대사 오역 (엔딩의 contain) | 핵심 서사 대사에 맥락 주석을 붙인 현지화 가이드 | 현지화 비용 증가 |
:::

## 4. 시나리오 — 두 축이 네 번의 시험으로 엮인다

::: callout key
**요약**
외적 축(란록·룩우드와의 저장소 경쟁)은 시간 압박을, 미스터리 축(이사도라의 네 기억)은 '다음 시험을 할 이유'를 만든다. 두 축은 저장소 앞의 마지막 질문 — 봉인할 것인가, 쓸 것인가 — 에서 만난다.
:::

### 정보 공개 설계

| 정보 | 최초 암시 | 공개 시점 | 플레이어에게 주는 의미 |
|---|---|---|---|
| 주인공만 고대 마법을 봄 | 마차 안, 봉인된 스크롤 상자가 주인공에게만 반응 | 그린고츠 금고 (1) | '선택받은 자' 판타지 확립 |

| 파수꾼이 이사도라를 죽였다는 진실 | 불탄 이사도라 초상화, 산 바카르의 불신 | 기억 4 (38) | 시험의 진짜 목적(힘을 감당할 자격 검증)이 드러나 엔딩 선택에 의미 부여 |
| 앤에게 저주를 건 범인 | 저주 당시 들었다는 말 | 지팡이 숙련에서 룩우드의 같은 말 (39) | 세바스찬 서사의 오해 해소 |

::: details 인물과 갈등 구조
인물 배치의 중심은 '주인공의 거울'인 **이사도라**와 '어둠의 마법을 가르치는 동료'인 **세바스찬**이다. 둘 다 '선의로 시작한 힘의 사용'이 무너지는 길을 보여 준다.

| 인물 | 표면적 목표 | 내적 욕망 | 변화 곡선 |
|---|---|---|---|
| 주인공 | 란록을 막고 고대 마법의 비밀을 밝힘 | 공백형 — 소속감, 힘의 의미를 플레이어가 채움 | 신입생 → 새로운 파수꾼 |
| 엘리자 피그 | 주인공 보호, 고대 마법 연구 | 아내 미리암의 죽음에 의미를 찾고 그녀의 연구를 완성 | 비밀주의 → 주인공을 믿고 희생 |
| 이사도라 모르가나크 | 고대 마법으로 사람들의 고통을 없앰 | 아들을 잃고 무너진 아버지를 구하고 싶음 → 모두의 고통을 없애야 한다는 확신 | 선의의 연구자 → 감정 흡입으로 강해짐 → 산 바카르에게 살해 |
| 세바스찬 샐로우 | 동생 앤의 저주 치료 | 가족을 지키기 위해서라면 금지된 마법도 불사 | 모험 동료 → 갈등 → 삼촌 솔로몬을 죽이고 고발·은폐 분기 |
| 란록 · 빅터 룩우드 | 저장소의 힘 확보 | 빼앗긴 것을 되찾을 힘 / 가문 권리 집착 | 불안한 동맹 → 결렬 → 각자의 최후 |

- **외적 갈등** — 고블린 반란 + 어둠의 마법사 연합 vs 주인공·파수꾼·교수진. 두 세력의 동맹은 이해관계뿐이라 결국 서로를 공격한다
- **내적 갈등** — '힘을 가진 자의 책임'. 다만 주인공의 내면은 대사로 거의 표현되지 않고 선택지로 위임된다
- **세계관 차원** — 지식을 숨길 것인가 쓸 것인가(파수꾼의 비밀주의 vs 이사도라의 치유 주장). 저장소 선택이 이 질문에 대한 플레이어의 답이 된다
:::

::: details 시나리오 평가
- **몰입도가 높은 지점** — 프롤로그 → 호그와트 도착 연출, 폴리주스 작전의 코믹 잠입, 니암의 시험(죽음의 성물 3단계 구성), 그래폰 비행, 로드곡의 죽음, 추모식
- **개연성이 약한 지점** — 교수진이 학생에게 반란 진압을 맡기는 구조, 란록의 명분이 폭력성으로만 소비됨, 용서받지 못할 저주의 무결과, 앤 저주 반전이 우연한 대사 콜백에 의존
- **페이싱** — 레벨 게이트가 챕터 사이에 강제 공백을 만들어 긴장이 끊긴다. 시험 사이 간격이 길어 마지막 두 기억이 후반에 몰린다
- **분기와 선택** — 실제 분기는 엔딩 컷신 수준이고, 저주를 써도 서사적 결과가 없어 체감 분기는 더 낮다. 재플레이 동기는 서사보다 '기숙사 롤플레이'에 있다
- **현지화 메모** — 한글판에서 봉인 엔딩의 contain이 반대 의미로 번역되어 피그의 마지막 격려가 '신념을 포기하는 장면'처럼 읽힌다는 지적
:::

## 5. 상세 분석 — 퍼시벌 랙햄의 시험

이후 세 번 반복되는 '파수꾼의 시험' 포맷의 첫 교본이며, 잠입·전투·퍼즐·보스·서사 보상이 한 퀘스트에 모두 들어 있어 메인 퀘스트의 설계 문법을 한 번에 볼 수 있다.

![퍼시벌 랙햄의 시험 — 목표 11개의 흐름](/images/fig-trial-flow.svg "탑 앞 합류부터 지도 내실 보고까지. 진행을 멈출 수 있는 지점은 텐트 속 편지(숨은 완료 조건)와 시험의 문(복귀 불가) 두 곳이다")

| 항목 | 내용 |
|---|---|
| 위치 | 노스 포드 수렁 북부 '산 바카르의 탑' → 탑 지하 시험 던전 → 지도 내실 |
| 선행 조건 | 메인 '지도 내실' 완료 + Lv11 |
| 예상 플레이타임 | 약 40–60분 — 던전 퍼즐·전투가 절반 이상 |
| 주요 보상 | 260 XP, 트로피, 파수꾼의 유물 1, 고대 마법 핫스팟 해금, 페트리피쿠스 토탈루스 튜토리얼 |

::: flow
탑 앞 합류 → 캠프 조사 (은신) → 매복 섬멸 → 탑 수색 · 피그 퇴장 → 숨은 입구 → 시험의 문 (복귀 불가) → 퍼즐 5 · 전투 3 → 펜시브 가디언 → 기억 1 → 지도 내실 보고
:::

| 콘텐츠 요소 | 배치 | 기능 | 다른 요소와의 연결 |
|---|---|---|---|
| 탐색 | 캠프 조사(편지), 탑 수색, 던전 방마다 상자 | 단서 획득, 루팅, 공간 파악 | 편지 → 란록이 파수꾼의 '이름'을 찾는다는 서사 정보 |
| 전투 | 캠프(은신 → 매복), 던전 전투 3회, 아레나 | 신규 적 체험, 주문 색 대응 복습 | 은신 튜토리얼과 직결. 보스 오브의 색 대응이 주문 카테고리 이해를 요구 |
| 퍼즐 | 던전 방 1–5 | 공간 전환(아치·웅덩이)과 아씨오 플랫폼 이동을 한 방에 하나씩 조합 | 전투와 번갈아 배치해 긴장·이완 교대 |
| 대화 | 도입(피그), 탑 최상층(퍼시벌), 종결 | 규칙 제시(혼자 치러야 함), 긴장 조성, 후속 떡밥 | 동행자 분리 → '나만의 시험' 프레이밍 |
| 보상 | 완료 시 + 던전 곳곳 | XP, 유물, 핫스팟 해금 | 유물 4개 → 파수꾼의 지팡이. 핫스팟 → 오픈월드 탐험 동기 |

::: cards 2
### 잘 설계된 점 {강점}
- **템플릿의 교본** — 구조가 이후 시험 3회에 재사용되도록 모듈화됨
- **동행자 분리 연출** — 피그가 입구에서 떠나는 순간 '선택받은 자' 판타지가 공간적으로 구현됨
- **메커닉의 단계적 조합** — 공간 전환 → 아씨오 플랫폼 → 포털 방향 → 두 플랫폼 조합, 방마다 규칙 하나씩
- **보상의 이중화** — 기능(핫스팟)과 이야기(기억)를 함께 줌. 보상 = 떡밥
### 문제점 {약점}
- 조사 목표의 완료 조건(텐트 편지)이 드러나지 않아 버그로 오인됨
- 되돌아갈 수 없는 입장 지점의 사전 고지 부족
- 펜시브 가디언이 다른 수호자전과 패턴이 비슷해 반복감
- 서사 보상(기억 1편) 대비 던전 분량이 길어 이야기 중심 플레이어에게 템포 저하
:::

::: details 개선안
| 개선 대상 | 제안 | 기대 효과 | 리스크 |
|---|---|---|---|
| 텐트 편지 단서 | 캠프 정리 후 피그의 힌트 VO, 목표 문구를 '란록의 흔적 찾기'처럼 구체화 | 정체 해소 | 과한 안내로 조사의 재미 감소 |
| 잠긴 문 오인 | 진행용 문은 열린 상태가 확실히 보이게, 잠긴 문은 자물쇠 아이콘 + '나중에 배움' 툴팁 | 경로 혼동 감소 | 알로호모라 복선의 신비감 약화 |
| 입장 전 준비 프롬프트 | 시험의 문 홀드 시 '되돌아갈 수 없음 · 물약과 주문 세트 확인' 확인창 | 준비 부족 방지 | 몰입 연출이 한 번 끊김 |
| 가디언 변주 | 던전에서 배운 공간 전환을 보스 패턴에 결합 | 퀘스트 고유 경험 강화, 메커닉 회수 | 난이도 급등, 제작 비용 |
:::

## 6. 이 역기획이 다음 문서로 넘기는 것

| 발견 | 이어지는 질문 | 다루는 문서 |
|---|---|---|
| 레벨 게이트는 완료도 게이트이고, 숨은 조건이 마찰을 만든다 | 메인은 탐험을 어떻게 강제하고 유도하며, 어디서 무너지는가 | [심층 분석](/analysis/hogwarts-legacy-deep-dive) ① 탐험 유도 |
| 선택의 결과가 회수되지 않고, 저주는 무결과다 | 결과 없는 선택 속에서 몰입은 어떻게 유지되고 무너지는가 | [심층 분석](/analysis/hogwarts-legacy-deep-dive) ② 선택과 몰입 |
| '되돌아갈 수 없음' 확인창, 일지체 로그, 보상 = 떡밥 구조 | 같은 패턴을 결말 재설계에 재사용할 수 있는가 | [재설계 제안](/analysis/hogwarts-legacy-ending-redesign) — 돌아올 수 없는 지점 확인창, 첫 시전 일지, 파수꾼의 임무 |
